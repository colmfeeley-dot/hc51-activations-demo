How file uploads work

This tool uses a two-step approach that works regardless of where it is hosted, with no CORS or authentication configuration required.

Step 1 — Upload the file to SharePoint. Click "Open SharePoint uploads folder" on any initiative's file section. This opens the HC51 uploads folder directly in your browser. Drag your file in — it lands in SharePoint immediately using your existing M365 session.

Step 2 — Link the file back. Type the filename in the link field. The tool automatically builds the correct SharePoint URL and attaches it to the initiative. Download arrows in the calendar then link directly to that SharePoint file.

Supported file types: PDF, PNG, JPG, PPTX, DOCX, XLSX, ZIP.
Files are stored at: Shared Documents/TRIAL - Activations Calendar/Uploads/[filename]
